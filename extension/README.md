# ИИ помощник

В этой папке лежит готовое расширение Chrome. На `chrome://extensions` включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку. После обновления на месте нажмите ↻ на карточке и перезагрузите вкладку почты.
