# ИИ помощник

Расширение для Chrome, которое помогает ответить на письмо. Вставьте фрагмент переписки, выберите **Ответить**, **Кратко** или **Разбор** и перенесите выбранный вариант в свой черновик. Отправку контролируете вы.

**Версия 0.3.1.** Ранее — AI Bro. Для демонстрации ключ не нужен. Для ответов модели подключите свой ключ DeepSeek в настройках. Поддерживается вставка в редакторы Яндекс Почты, Gmail и Outlook Web; в остальных случаях ответ можно скопировать.

В 15-секундном ролике показан путь от вопроса о встрече до черновика ответа. Короткие щелчки отмечают нажатия; музыки и закадровой речи нет.

### Разработка

Готовое расширение находится в `extension/`: его можно загрузить без сборки. `manifest.json` задаёт разрешения и точки входа; `sidepanel.*` и `options.*` отвечают за интерфейс, `content.js` — за интеграцию с почтой, `background.js` и `lib/` — за запросы и обработку текста. Скрипт `extension/package.ps1` собирает ZIP расширения с манифестом в корне (отдельный формат для магазина). Пользовательский комплект дополнительно содержит инструкцию и ролик.
