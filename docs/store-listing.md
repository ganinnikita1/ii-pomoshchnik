# Карточка расширения

**Название:** ИИ помощник

**Описание:** Вставьте текст письма, получите варианты ответа или краткую сводку и перенесите результат в черновик почты.

Помощник открывается сбоку от письма. Выберите «Ответить», чтобы подготовить черновик, «Суть», чтобы быстро понять запрос, или «Разбор», чтобы выделить детали. Проверьте текст перед отправкой. Без ключа доступна локальная демонстрация, для ответов модели используется ваш API-ключ DeepSeek.
