Первый запуск

Установите расширение и попробуйте подготовить черновик ответа. Без ключа можно пройти весь пример в деморежиме. Для ответа модели на своё письмо понадобится личный API-ключ DeepSeek. Для Google Chrome 116 или новее на компьютере.

01

Установите расширение

  1. Полностью распакуйте ZIP в постоянную папку на компьютере. Внутри найдите папку extension: в ней должен лежать файл manifest.json.
  2. В адресную строку Chrome вставьте chrome://extensions и нажмите Enter.
  3. Справа вверху включите Режим разработчика. Нажмите Загрузить распакованное расширение и выберите папку extension.
  4. Появится карточка ИИ помощник. Нажмите значок пазла у адресной строки и закрепите помощник булавкой. Оставьте распакованную папку на месте: Chrome запускает расширение из неё.
02

Подключите модель, если у вас есть ключ

Где запросить ключ. Напишите в Telegram @oosbwg или на почту ganin@rae.moscow.

Хотите сначала попробовать без ключа? Пропустите этот раздел и перейдите к первому ответу. В деморежиме помощник покажет три примера без обращения к DeepSeek.

  1. Откройте настройки расширения. Они появляются при первой установке; позже их можно открыть шестерёнкой в боковой панели.
  2. В разделе Подключение DeepSeek вставьте свой ключ в поле Ключ DeepSeek. Личный API-ключ можно получить в кабинете DeepSeek.
  3. Нажмите Обновить список моделей. Если Chrome спросит, разрешите доступ к api.deepseek.com. В поле Модель выберите один из вариантов, которые вернул DeepSeek для вашего ключа.
  4. Нажмите Сохранить настройки. Вернитесь во вкладку почты.

В этом режиме текст запроса передаётся DeepSeek, и провайдер может списывать средства с вашего баланса. Ключ не передавайте вместе с архивом.

03

Подготовьте первый ответ

  1. Откройте Яндекс Почту. Нажмите значок ИИ помощник в Chrome — справа появится панель.
  2. Вставьте в поле Исходное письмо этот учебный текст:
    Здравствуйте! В четверг в 15:00 обсудим макет. Подтвердите, пожалуйста, время.
  3. Нажмите Ответить. Прочитайте варианты и выберите подходящий. Кратко покажет главное в письме, а Разбор разложит его по пунктам.
  4. В той же вкладке почты откройте ответ или новое письмо. Щёлкните в тело черновика, затем в панели нажмите Вставить в письмо под выбранным вариантом.
  5. Проверьте текст, имена и время. Письмо остаётся черновиком; отправляете его вы. Для тренировки можете оставить его без адресата.

Хотите писать в своём тоне? В настройках откройте Ваш стиль письма, выберите тон и длину, посмотрите пример и нажмите Сохранить стиль. В разделе Свои правила для ответов можно добавить собственное пожелание.

?

Если возникла трудность

  • Chrome не видит манифест. Выберите папку extension, где виден manifest.json, а не сам ZIP или папку с инструкцией.
  • Список моделей не загрузился. Проверьте ключ, соединение и разрешение на api.deepseek.com, затем снова нажмите Обновить список моделей.
  • Текст не появился в черновике. Нажмите Копировать под ответом, щёлкните в тело письма и вставьте текст: Ctrl+V на Windows или Linux, ⌘V на Mac.
