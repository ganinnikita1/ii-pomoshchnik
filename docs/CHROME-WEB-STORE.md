# Пакет для магазина

1. Проверьте версию и разрешения в `extension/manifest.json`, интерфейс и политику обработки данных.
2. Запустите `pwsh -File ./extension/package.ps1`. В `extension/dist/` появится `ii-pomoshchnik-<версия>.zip` с `manifest.json` в корне.
3. Проверьте новую сборку в отдельном профиле Chrome. Для магазина используйте именно ZIP из шага 2, без внешней папки, инструкции и ролика. Для обмена между людьми используйте пользовательский комплект.
4. Перед публикацией обновите графику актуальными скриншотами и укажите доступный URL политики конфиденциальности. Материалы прежних версий не описывают текущий интерфейс.
