# ИИ помощник · Обработка данных

Версия 0.3.0 · 18 ноября 2026 года

**Демонстрация без ключа.** Для генерации демонстрационных ответов используются локальные шаблоны. Письма не отправляются из расширения. Вы переносите текст в панель и сами выбираете, какой ответ использовать.

**Режим с ключом.** Расширение обращается напрямую к `https://api.deepseek.com` по вашему запросу. Провайдеру передаются API-ключ для авторизации и данные, необходимые для ответа: введённый текст, контекст диалога и применяемый профиль стиля. Собственного сервера-посредника у расширения нет. Учитывайте правила вашей организации, прежде чем передавать провайдеру рабочие письма.

**Хранение.** Настройки, ключ, профиль стиля и история находятся в локальном хранилище расширения в вашем профиле Chrome. Это не отдельное зашифрованное хранилище секретов. Не распространяйте папку профиля браузера. Общий установочный архив содержит файлы программы, а не данные профиля.

**Доступ к почте.** Скрипт интеграции работает на перечисленных в манифесте доменах веб-почты. Он помогает открыть панель и вставить ответ в редактор. При обращении к тексту черновика по явному действию расширение читает содержимое редактора. Вставка и отправка — отдельные действия: кнопку отправки нажимает пользователь.

**Голос.** Если включить диктовку, распознаванием управляет браузер. Возможность передачи звука сервису распознавания зависит от браузера и его настроек. Для работы расширения голос не требуется.

**Удаление.** Настройки расширения позволяют сбросить сохранённые данные. При удалении расширения Chrome очищает его локальное хранилище. Уже переданные провайдеру запросы и черновики, сохранённые самой почтой, этим не удаляются.

Контакт по проекту — через Issues его репозитория на GitHub. Не публикуйте в обращениях настоящие письма или ключи.
